# Context Mode

- Think in code, not raw context.
- Prefer sandboxed execution over large inline outputs.
- Prefer one scripted analysis over many tool calls.
- Never fetch/read large raw content into context.
- Use indexed/searchable retrieval whenever possible.
- Write large artifacts to files, not chat output.
- Search session memory/history before asking the user.
- Use concurrency only for I/O-bound operations.
