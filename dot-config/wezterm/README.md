# Wezterm

> My [Wezterm](https://wezfurlong.org/wezterm) custom configuration

- Fonts
  - [FiraCode Nerd Font](https://github.com/ryanoasis/nerd-fonts/tree/master/patched-fonts/FiraCode)
  - [Cascadia Nerd Font](https://github.com/ryanoasis/nerd-fonts/tree/master/patched-fonts/CascadiaCode)
- Theme - Custom configuration based:
  - [Catppuccin Frappe](https://github.com/catppuccin/wezterm)
  - [Gogh Chalkboard](https://github.com/Gogh-Co/Gogh)

## Custom Keymaps

### General

| Keys                | Action                 |
| ------------------- | ---------------------- |
| <kbd>Ctrl+/</kbd>   | `Leader Key`           |
| <kbd>Leader+a</kbd> | `Active Tmux commands` |

### Tmux

#### Miscellaneous

| Keys                        | Action                  |
| --------------------------- | ----------------------- |
| <kbd>Ctrl+Alt+Shift+i</kbd> | `Install dependencies`  |
| <kbd>Ctrl+Alt+Shift+u</kbd> | `Update dependencies`   |
| <kbd>Ctrl+Alt+r</kbd>       | `Reload configurations` |
| <kbd>Ctrl+Alt+[</kbd>       | `Copy mode`             |

#### Panels

| Keys                        | Action             |
| --------------------------- | ------------------ |
| <kbd>Ctrl+Alt+\\</kbd>      | `Vertical Split`   |
| <kbd>Ctrl+Alt+-</kbd>       | `Horizontal split` |
| <kbd>Ctrl+Alt+Shift+}</kbd> | `Rotate panel`     |
| <kbd>Ctrl+Alt+Shift+{</kbd> | `Rotate panel`     |
| <kbd>Ctrl+Alt+x</kbd>       | `Kill panel`       |
| <kbd>Ctrl+Alt+z</kbd>       | `Zoom panel`       |
| <kbd>Ctrl+Alt+Shift+h</kbd> | `Resize to left`   |
| <kbd>Ctrl+Alt+Shift+j</kbd> | `Resize to top`    |
| <kbd>Ctrl+Alt+Shift+k</kbd> | `Resize to down`   |
| <kbd>Ctrl+Alt+Shift+l</kbd> | `Resize to right`  |

#### Window

| Keys                    | Action                |
| ----------------------- | --------------------- |
| <kbd>Ctrl+Alt+1-9</kbd> | `Change window focus` |
| <kbd>Ctrl+Alt+n</kbd>   | `New window`          |
| <kbd>Ctrl+Alt+x</kbd>   | `Kill window`         |

#### Apps

| Keys                        | Action                       |
| --------------------------- | ---------------------------- |
| <kbd>Ctrl+Alt+b</kbd>       | `Open Btop`                  |
| <kbd>Ctrl+Alt+c</kbd>       | `Tmux thumbs`                |
| <kbd>Ctrl+Alt+g</kbd>       | `Open Lazygit`               |
| <kbd>Ctrl+Alt+k</kbd>       | `Open Sesh modal`            |
| <kbd>Ctrl+Alt+u</kbd>       | `Open Tmux URL search modal` |
| <kbd>Ctrl+Alt+t</kbd>       | `Open Tig`                   |
| <kbd>Ctrl+Alt+Shift+b</kbd> | `Open Btm`                   |
| <kbd>Ctrl+Alt+Shift+g</kbd> | `Open Gh Dash`               |
